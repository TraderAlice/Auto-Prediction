# Falsifiable exploration axes

Status: completed mainline construction — `ADOPT`

Issue: [#217](https://github.com/luokerenx4/my-little-pony/issues/217)

## Product question

What kind of novelty should a persistent arbitrage-discovery machine pay for?
The first operationally successful V2 trailhead reveals that an axis named in
a prompt is not yet an ontology. `SURFACE_DOMAIN` accepted a new venue and
rules expression around the already known election-domain component-seat /
chamber-control mechanism. The Agent optimized the easiest defensible reading
of “surface” rather than the intended search mutation.

Venue, protocol and wording variation may be valuable for interoperability and
settlement research, but they are representation changes. Party and geography
are mechanism parameters. Neither is evidence that the underlying world domain
changed. Treating them as interchangeable makes search yield look better while
the machine remains trapped in a local semantic neighborhood.

## Decision

Compile every exploration lens into an exact, provider-free axis contract bound
to the source prototype input. The contract declares the source predicate
families and institutions plus the evidence required from a terminal candidate.
The first-party result builder computes candidate predicate families from the
exact inspected titles and returns an inspectable assessment.

For `SURFACE_DOMAIN`, at least one candidate predicate family must be outside
the source families, and at least one non-`UNCLASSIFIED` candidate family must
be present. Cross-venue, protocol, wording, party, state or geography change
alone is explicitly insufficient. An Agent submission that fails this contract
is rejected in-loop with a bounded diagnostic and retains no trailhead.

The other axes receive explicit contracts in the same object even where their
first deterministic gate remains intentionally weaker:

- `SUBJECT_AND_GEOGRAPHY` requires parameter variation beyond known source
  subject values without claiming world-domain novelty;
- `AGGREGATE_INSTITUTION` requires a candidate aggregate institution family
  outside the source institution set while preserving the component/aggregate
  posture;
- `COUNTEREXAMPLE_FRONTIER` requires a cited transfer-test or counter-scenario
  reference and keeps negative evidence preferable to a forced positive.

No gate proves the analogy true. It only proves that the submitted candidate
actually varies the dimension whose search budget it consumed.

The first-party implementation now binds every semantic input to a
content-addressed axis contract containing source predicate families,
institution families, and exact source parameter values. Candidate assessment
replays exact inspected titles into predicate families, component/aggregate
role refs, shared institution families, non-source parameter signals, and
observed novelty dimensions. `UNCLASSIFIED` remains visible but cannot create
world-domain admission.

Focused fixtures reject the exact live failure shape—cross-venue Iowa
Republican seat to Republican Senate control—from `SURFACE_DOMAIN`; admit an
election-to-Formula-1 component/constructors pair with `SPORTS_RESULT` as the
grounded domain signal; and distinguish known Iowa from new Georgia in the
parameter lane. Positive gate failure throws through the existing tool host,
so the runtime can continue its bounded repair loop without retaining a
trailhead.

Live SQLite replay retains the historical V2 trailhead and its cost as one
explicit pre-gate positive, does not relabel it, and leaves the successor
`SURFACE_DOMAIN` input eligible. Studio displays the requested admission rule,
source domains, and pre-gate count. Browser qualification at 5174 shows the
four cards coherently without application errors; the initial HTTP 502 during
hot-reload recovery cleared after the control plane reached `READY` and a page
reload.

The first V3 Terra/high qualification then exercised the compact protocol over
one exact `SURFACE_DOMAIN` input. It completed seven model invocations in about
220 seconds, consuming 167,012 input, 2,812 output, and 1,718 reasoning tokens
(171,542 total). One malformed exhaustion reference was rejected and repaired
inside the same bounded run. The accepted result was principled negative
memory, not a forced trailhead: the Agent inspected Baltimore and Buffalo AFC
Championship winner listings and concluded that they are parallel named-team
outcomes without distinct component and aggregate roles, so the prototype's
trigger/state/non-necessary/non-sufficient structure did not transfer.

This is a useful selection result. V3 prevented representation novelty from
being retained as world-domain novelty and the Agent preferred exact
exhaustion over inventing a positive. The run also exposes the next bottleneck:
the generic OR-pattern corpus search turns broad signals such as `winner`,
`control`, and `seat` into parallel alternatives more readily than it finds a
component outcome paired with an aggregate outcome. The next plan should make
retrieval role-aware while keeping role assignment and semantic truth outside
deterministic search authority.

After the specimen, an anonymous catalog refresh retained 4,353 listings from
seven sources; five healthy sources contributed 4,313 listings to the current
qualified corpus and two stale-after-failure sources were excluded. The larger
semantic coverage correctly reopened the lens while retaining the V2 pre-gate
trailhead and V3 exhaustion as historical evidence. A prior exhaustion never
silently claims coverage over newly observed listings.

Full qualification passes: 108 control-plane files / 731 tests, 5 Studio files
/ 30 tests, TypeScript checks, production Studio build, and browser inspection
at 5174. The only build diagnostics are the repository's known Node 22 versus
Node 24 engine warning and Vite chunk-size warning.

## Selection

`ADOPT`. Exact axis admission materially improves the quality of retained
research memory and preserves falsification as a first-class outcome. It adds
no provider call to the verifier and no authority beyond search routing. The
remaining search-yield problem belongs to a successor role-aware retrieval
plan rather than weakening this gate.

## Selection gates

- Axis assessment starts zero provider/model calls and performs no writes by
  itself.
- Exact inspected listing titles and source prototype input are sufficient to
  replay every classification.
- `VENUE` / protocol / wording difference cannot satisfy `SURFACE_DOMAIN`.
- `UNCLASSIFIED` cannot manufacture world-domain novelty.
- Rejection retains a bounded first-party diagnostic but no semantic result.
- Acceptance remains search-routing evidence only, with no semantic,
  probability, certificate, execution, external-write or value-moving authority.

## Non-goals

- proving a mechanism analogy from predicate-family difference;
- hidden embeddings or model confidence as admission authority;
- deleting pre-gate historical trailheads;
- automatic recurring dispatch;
- treating every axis as mutually exclusive in the world itself.
