# Agent hypothesis-attention loop

Issue: https://github.com/luokerenx4/my-little-pony/issues/239

## Decision

Close the V14 measurement loop by returning the exact intent-attention
portfolio in the compact mechanism-exploration lens. The Agent sees cohort
observation/comparability/realization counts, evidence debt, known input cost,
the first observation candidate and portfolio identity.

The recommendation is deliberately descriptive. It does not require the named
intent, select an exact family or test, choose a query, create work, schedule,
dispatch or grant semantic/probability/execution authority. The existing
first-party family validation remains the only authority over whether an
`EXTEND / REPLICATE / DIFFERENT_TEST` declaration is internally valid.

## Selection

Adopt when fixture qualification proves exact lineage and no authority growth,
and a separately authorized Terra/high specimen receives the portfolio and
chooses a legal extension experiment without hard-coded intent enforcement.
Reject if the portfolio becomes a hidden scheduler, an ineligible family can be
fabricated, or the context materially regresses loop cost.

Complete episode `9aeb81d2…` is replayable. Its six-call hypothesis window used

it as priority one because there is still no realized extension.

After a full control-plane restart, episode `9aeb81d2…`, report `f590f231…`,
portfolio `71d52d6e…`, cohort order, classification, exact counts and usage all

This selects the attention loop while exposing the next bottleneck: the Agent
guessed rigid sports title cues (`game` + `winner`, `championship` + `winner`)
that returned no role hits, then a broad fallback admitted election noise.
The next generation must improve query-language discovery and preserve exact
fallback coordinates before spending another extension attempt.

## Selection result

and the resulting negative experiment updates the portfolio rather than being
mistaken for success.
