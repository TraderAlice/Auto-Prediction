# Hypothesis-intent attention portfolio

Issue: https://github.com/luokerenx4/my-little-pony/issues/237

## Decision

Compile exact V12 hypothesis-intent realization reports into three distinct
research portfolio roles:

- `EXTEND` seeks evidence-frontier expansion inside an exact prior family;
- `REPLICATE` supplies an independent control even when novelty is not the aim;
- `DIFFERENT_TEST` applies mutation pressure across sibling exact tests.

The provider-free compiler preserves observation/comparability/realization
counts, independent inputs/runs, accepted terminals, rejected effects, exact
new listing/pair coordinates and hypothesis-span token usage. It orders
observation debt before already observed roles. It deliberately has no scalar
utility score: raw hits, replication and new coordinates are unlike evidence,
not interchangeable reward points.

The portfolio may name the highest-value missing observation. It cannot create
a task, schedule or dispatch a campaign, choose a query, assert semantics or
probability, publish a certificate, execute, write externally or move value.

## Selection

Adopt when live retained evidence identifies the missing `EXTEND` cohort as a
coverage gap while preserving realized `REPLICATE` and `DIFFERENT_TEST` as
different nonzero roles. Reject if unmeasurable reports count as verified new
frontier, token cost becomes an opaque utility score, or the read model gains
policy authority.

## Live evidence

The first V4 memory / V9 world-state projection compiles three exact reports:

- `EXTEND`: zero observations, `COVERAGE_GAP`, zero attributed spend;
- `DIFFERENT_TEST`: two observations, one comparable realized expansion and one
  unmeasurable predecessor, 16 hypothesis-span calls / 456,504 input, two
  reports but only one comparable new listing ref (the unmeasurable report is
  excluded from frontier totals);
- `REPLICATE`: one comparable realized independent control, five
  hypothesis-span calls / 127,051 input and zero rejected effects.

The portfolio selects `EXTEND` as the next observation candidate because no
experience distribution exists for it—not because it is presumed profitable.
Its selected `345e9573…` identity and cohort bodies are derived only from durable exact
reports and episodes. Studio renders the three cohorts as one compact comparison
block and labels the output `DESCRIPTIVE ONLY`.
