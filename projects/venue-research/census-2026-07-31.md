This is protocol research, not an availability or legal eligibility determination for any user. A venue can be useful for contract truth and pricing research without having execution authority.

## Architecture-changing findings

1. Gemini is no longer just a research candidate. Its official surface includes public catalog, partial and differential depth, order lifecycle streams, Combo/RFQ, maker-only semantics, and a full sandbox. It is a first-wave adapter.
2. Myriad already separates a canonical Question from per-chain Markets. That is direct real-world evidence for Claim-before-Listing rather than a purely internal preference.
3. Myriad currently exposes both AMM and order-book execution modes under one market API. Mechanism belongs to listing/capability identity, not venue identity alone.
4. Predict.fun testnet is public while mainnet requires an API key. Qualification must bind environment/protocol identity, not merely venue name.
5. Polymarket US and Polymarket Global have separate documentation, base URLs, account semantics, and contract/instrument types. They remain separate adapters.
6. Public APIs sometimes return monetary decimals as JSON numbers (Myriad), while others guarantee decimal strings (Gemini). Raw codecs must accept the venue representation, but normalized Core must reject binary floating-point conversion and parse the original lexical token.

## Endpoint evidence

The initial reachability probe used small, read-only requests only:

- `https://gamma-api.polymarket.com/markets?active=true&closed=false&limit=1` → 200 JSON
- `https://gateway.polymarket.us/v1/markets?active=true&limit=1` → 403 Cloudflare HTML
- `https://external-api.kalshi.com/trade-api/v2/markets?limit=1&status=open` → 200 JSON
- `https://api.gemini.com/v1/prediction-markets/events?status=active&limit=1` → 200 JSON
- `https://openapi.opinion.trade/openapi/market?status=activated&limit=1` → 200 JSON
- `https://api-testnet.predict.fun/v1/markets?first=1` → 200 JSON
- `https://api.limitless.exchange/markets/active?limit=1` → 200 JSON
- `https://api-v2.myriadprotocol.com/markets?page=1&limit=1&state=open` → 200 JSON

No credential, order, signature, transaction, deposit, withdrawal, or value-moving endpoint was used.
