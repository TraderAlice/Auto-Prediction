# Project Format

- `packages/`: first-party runtime packages with source and focused tests.
- `projects/venue-research/`: dated official-source census and capability evidence.
- `projects/fixtures/`: small immutable raw protocol fixtures plus provenance.
- `projects/claims/`: reviewed claim, resolution, outcome, listing, and link artifacts.
- `projects/campaigns/`: replay/shadow campaign definitions and manifests.
- `docs/design/`: stable current design truth.
- `plans/`: active execution records, findings, and deviations.

Dense streams are excluded from Git; their manifests and hashes remain tracked.
